Como funciona a validação pela base de matrículas?

1
Recepção da Matrícula

O usuário envia o código no canal autorizado do servidor ou responde a mensagem privada (DM) do FlexBot.

2
Consulta à Base (`matriculas.json`)

O FlexBot consulta se a matrícula consta na base autorizada oficial da Prefeitura do Rio.

3
Concessão do Cargo no Servidor

Caso a matrícula seja válida, o cargo (Role) parametrizado na regra é atribuído automaticamente.
